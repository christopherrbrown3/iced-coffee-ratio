# Iced Coffee Calculator visual directions

Two north-star mobile concepts generated from the confirmed 1950s-advertising palette.

- **Direction A — Countertop Advertisement:** one fast calculator surface with the amount as the dominant control.
- **Direction B — Three-Panel Comic:** a Pick → Tune → Brew workflow with stronger comic-panel structure.

The original pour illustration is retained here as an exploration. The production interface uses the ice mascot as its single visual protagonist.
